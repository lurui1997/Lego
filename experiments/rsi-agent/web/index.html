How it works

一条闭环，自己改自己。

人只给目标、验收命令、迭代次数和间隔。其余交给本机 agent：改 runner、提示和工具，直到冻结验收通过。

  1. 01

    任务

    读 task.json，把验收命令抄进当次 run，整次只跑这一份。

  2. 02

    Agent

    非交互调用 Cursor CLI，工作区锁在本实验目录。

  3. 03

    冒烟

    语法检查加上 --help。入口搞挂，立刻硬回滚。

  4. 04

    验收

    跑冻结命令。通过即停；否则 sleep 后再来一轮。

Safety

验收被冻结。
入口被保护。

Agent 可以改 src/、prompts/ 和 test/。不能改当次 acceptance.txt，也不能把验收改成永远成功。

Snapshots

独立 Git，
不碰主仓。

每轮快照写在独立 GIT_DIR。不自动 push，也不往 Lego 仓库提交。

Smoke

搞挂就回滚。

node --check src/cli.js 与 cli --help 失败时，回到上一份冒烟通过的快照。

Trust

需要已登录的 agent。

真跑前执行 agent status。npm test 只测 harness，不打真模型。

Tasks

人写任务，机器迭代。

当前仓库里的任务从本机 tasks/ 读取。

retry-on-429

LLM 返回 429 时自动重试一次再失败

验收 node --test test/retry.test.js

Runs

最近一次自我改进。

数据来自 state/。还没有跑过时，这里会保持安静。

暂无运行记录。

Get started

一条命令，开始循环。

可选环境变量：RSI_CURSOR_BIN、RSI_MODEL、RSI_CURSOR_TIMEOUT_MS。

cd experiments/rsi-agent
npm test
node src/cli.js run tasks/retry-on-429

RSI 是 lurui 的 Lego 仓库里的个人实验，不是产品。循环只发生在本机实验目录。
